================================================================================
CLI COMMANDS (run_analytics.py)
================================================================================

python run_analytics.py backfill --days 30
    → Backfill last 30 days of analytics

python run_analytics.py daily [--date YYYY-MM-DD]
    → Run daily analytics aggregation

python run_analytics.py weekly [--week YYYY-Www]
    → Run weekly analytics aggregation

python run_analytics.py alerts
    → Run alert checks and show active alerts

python run_analytics.py schedule [--immediate]
    → Start analytics scheduler

python run_analytics.py ml-train [--n-estimators 100] [--save ml_model.pkl]
    → Train ML prediction model

python run_analytics.py ml-predict [--date YYYY-MM-DD] [--load ml_model.pkl]
    → Generate ML predictions

python run_analytics.py ml-evaluate [--date YYYY-MM-DD]
    → Evaluate ML prediction accuracy

python run_analytics.py full-pipeline [--days 30]
    → Run complete analytics pipeline

================================================================================
ML FEATURES (ml_predictor.py)
================================================================================

Market Features Extracted:
- atr                    - Average True Range
- atr_percentile         - ATR vs 90-day range
- trend_strength         - Price momentum / ATR ratio
- chop_index             - Choppiness index (0-100)
- realized_volatility    - Annualized volatility %
- volatility_rank        - Volatility percentile
- rsi                    - Relative Strength Index
- momentum               - 20-bar price momentum
- recent_swing_count     - Swing high/low count
- regime_duration_bars   - Time in current regime
- regime_encoded         - Regime type (TREND/RANGE/VOLATILE)
- killzone_encoded       - Trading session
- time_of_day_encoded    - Time category

Target: Next-day Sharpe ratio
Model: RandomForestRegressor (100 trees)
Output: Prediction + recommendation (TRADE/REDUCE_SIZE/PAUSE)

================================================================================
QUICK START GUIDE
================================================================================

1. Install dependencies:
   pip install apscheduler scikit-learn scipy

2. Initial backfill:
   python run_analytics.py backfill --days 30

3. Train ML model:
   python run_analytics.py ml-train --n-estimators 100 --save ml_model.pkl

4. Start scheduler:
   python run_analytics.py schedule --immediate

5. OR run full pipeline:
   python run_analytics.py full-pipeline --days 30
