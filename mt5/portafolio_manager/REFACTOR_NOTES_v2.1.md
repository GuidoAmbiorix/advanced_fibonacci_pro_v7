# God-Level Refactor Notes v2.1

**Date:** January 27, 2026
**Version:** 2.1 (Institutional Architecture)

## 🚀 Overview

We have successfully completed the "God-Level" refactor. The system has moved from a "Simulation" approach to a "Encapsulation" approach.

**Old Architecture (Simulated):**

- `Symbol_Engine.mq5`: Real trading logic.
- `Portfolio_Governor.mq5`: Simplified "Signal Strategy" + "Trade Manager" that tried to mimic the Engine.
- **Problem:** Logic drift. The Governor was never 100% identical to the Engine.

**New Architecture (Encapsulated):**

- `Include/Engines/SymbolEngineWrapper.mqh`: **THE BRAIN**. Contains 100% of the logic (SMC, MTF, Risk, Adaptive).
- `Symbol_Engine.mq5`: **THE SINGLE SHELL**. Instantiates 1 Wrapper.
- `Portfolio_Governor.mq5`: **THE MULTI SHELL**. Instantiates 20+ Wrappers (one per symbol).

## 🛠️ Key Changes

### 1. The Wrapper (`CSymbolEngineWrapper`)

- Located in `Include/Engines/SymbolEngineWrapper.mqh`.
- This class is a self-contained trading machine.
- It has `GetDefaults()` to load institutional-grade settings automatically.
- It handles: `OnTick`, `SMC_Analysis`, `Risk_Calculations`, `Execution`, `Trailing_Stops`.

### 2. The Governor (`Portfolio_Governor.mq5`)

- **Parallel Processing**: Instead of one loop, it manages an array: `CSymbolEngineWrapper *g_engines[]`.
- **High-Level Control**: It loads `GetDefaults()` for the engine, and ONLY overrides the specific parameters you exposed in the Inputs (Strategy & Risk).
- **Reduced Inputs**: You no longer need 100+ inputs in the Governor. You only need the ones you want to _change_ from the defaults.

### 3. Cleanup

- **DELETED**: `Include/TradeManager.mqh` (The old simulation logic).
- **UPDATED**: `Symbol_Engine.mq5` is now just a thin wrapper around the class.

## 📋 How to Configure

1.  **To change core logic (SMC, Trailing Rule, etc.):**
    - Edit `Include/Engines/SymbolEngineWrapper.mqh`.
    - This updates BOTH the Standalone EA and the Governor instantly.

2.  **To change specific strategy settings (e.g. RSI Period):**
    - Change the Input in the Governor/EA.
    - The Input overrides the Default.

## ✅ Verification

- **Logic Parity**: 100%. The code running in the Governor IS the code running in the Standalone EA.
- **Performance**: The Governor effectively runs 20 charts worth of logic in one place. Ensure your VPS has decent CPU if running extensive SMC on M1 timeframe. M5/H1 is optimal.
